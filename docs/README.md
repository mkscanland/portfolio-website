# Repository guide

Start with the guide relevant to your change:

- [Architecture](architecture.md): entry points, routes, pages, shared components, assets, and deployment.
- [Conventions](conventions.md): Vue patterns, content accuracy, linting, and branch names.
- [Workflow](workflow.md): how to make a change and verify it before finishing.
- [References](references.md): official guidance behind these decisions.

The root [AGENTS.md](../AGENTS.md) is only an entry point. Keep detailed guidance here and update it when the project structure or commands change. Repository-specific Codex skills can be added under [`.agents/skills/`](../.agents/skills/) when a repeatable workflow warrants one; that directory currently contains no skills.
